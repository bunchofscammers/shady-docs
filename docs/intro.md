# ShadyUI

ShadyUI is a framework-agnostic component standard for professionally untrustworthy interfaces. It takes inspiration from fake currency generators, suspicious download pages, impossible giveaways, and other deceptive visual patterns, but implements them as transparent, accessible, and harmless software.

The project is in pre-alpha. This website currently documents the intended architecture and contribution workflow; component work will be added by the maintainers later.
