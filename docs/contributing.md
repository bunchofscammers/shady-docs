# Contributing

ShadyUI is at the infrastructure stage. Before proposing a component or public API, open an issue in the relevant repository so the behavior can be discussed across frameworks.

All changes require a pull request, passing CI, and one approving review. See the organization-wide [contribution guide](https://github.com/bunchofscammers/.github/blob/main/CONTRIBUTING.md) for details.
